Prueba de Funcionalidad

Si puedes ver esta página correctamente con el header y footer funcionando, significa que los componentes reutilizables están funcionando perfectamente.

El header debe tener: - Logo G2R visible - Menú de navegación funcionando - Selector de idioma funcionando - Menú hamburguesa en móvil

El footer debe tener: - Logo G2R - Enlaces útiles - Información de contacto - Redes sociales
